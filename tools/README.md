# Tools

Dev-only executables. Nothing here ships in a build.

- **`gsi-replay/`** — Replay a recorded fixture session into a running dev build. What `pnpm dev:replay` drives.
- **`gsi-record/`** — Capture a live GSI session to a fixture file.
- **`frame-labeler/`** — Annotate frames for the CV corpus in fixtures/frames.
- **`atlas-build/`** — Build hero, item, and digit template atlases per HUD scale.
- **`setup-gsi-cfg/`** — Write the gamestate_integration cfg and generate the per-install GSI token.
